# S4.9 — Final Unseen-Image Evaluation

## Purpose

S4.9 freezes the four S3.13 candidate checkpoints and evaluates them on
Dataset 1 images that were not used for training. Model selection happens on
`valid` only. The untouched `test` split is confirmation and is not used to
select a model.

## Dataset protocol

- Gallery: Dataset 1 `train` only (4328 images / 1494 product groups).
- Development generalization: Dataset 1 `valid` queries against the train gallery.
- Final confirmation: Dataset 1 `test` queries against the train gallery.
- Query images are never inserted into the gallery.
- Product identity is never inferred from filenames.
- Dataset 1 `valid` and `test` product groups are singleton groups, so exact
  product retrieval is not a valid automatic ground-truth metric on these
  splits. The automatic ground truth is the manifest category.

## Automatic metrics

For every query, the existing S3.8/S3.9 product retrieval path returns Top-10
unique products. We report:

- category Top-1 hit
- category Top-5 hit
- category Top-10 hit
- category MRR
- mean first correct-category rank
- the same metrics per category

Each query record retains the ranked Top-10 product IDs, categories,
similarities, and matched gallery images. These records are the evidence set
for human visual-relevance annotation.

## Model selection and test integrity

The four frozen candidates are compared on `valid` using this fixed priority:

1. validation category Top-1
2. validation category Top-5
3. validation category MRR

The selected model is then evaluated on `test`. Test results are not used to
change the selection. This preserves the test split as an unseen confirmation
set. If a new model is proposed after observing test results, it starts a new
development/model-selection cycle and the original test result remains a
historical benchmark.

## Robustness protocol

A deterministic subset of validation queries is evaluated under:

1. original image
2. +12 degree rotation, bilinear, `expand=False`
3. +20% brightness
4. centered 90% crop
5. 50% resize followed by the normal preprocessing resize

For every condition we report category Top-1/5/10 and category MRR. The
robustness pass is a development diagnostic, not a reason to tune on test.

## Human visual-relevance benchmark

Category correctness is not equivalent to visual similarity. S4.9 therefore
exports Top-10 candidates so a later small held-out annotation set can label
visual relevance. Exact visual-search quality should be supported by this
human-labeled benchmark rather than category accuracy alone.

## Command

Use the four S3.13 best checkpoints. The runner automatically reuses the
corresponding S3.13 train gallery when its `.pt` and metadata files are present;
otherwise it rebuilds the gallery from the checkpoint.

```bash
python scripts/run_s4_9_final_evaluation.py \
  --checkpoint s3.4_hybrid=PATH_TO_CHECKPOINT \
  --checkpoint s3.5_random=PATH_TO_CHECKPOINT \
  --checkpoint s3.5_same_category=PATH_TO_CHECKPOINT \
  --checkpoint s3.5_cross_category=PATH_TO_CHECKPOINT
```

Optional flags:

- `--device auto|cpu|cuda`
- `--batch-size 16`
- `--num-workers 0`
- `--robustness-queries 100`
- `--skip-robustness`

Outputs are written under `experiments/final_evaluation/s4.9/`.
