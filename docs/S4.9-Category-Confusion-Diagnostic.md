# S4.9 — Category Confusion Diagnostic

This diagnostic closes the evidence-analysis part of S4.9 without changing the
frozen MVP model.

## Frozen contract

- Model: `s3.5_cross_category`
- Split: `valid`
- Evidence: completed S4.9 human-relevance annotations
- Test labels: not used
- Inference: not rerun
- Training: unchanged

A Top-1 result from another jewelry category is described as **embedding-space
category confusion**. The current MVP is a retrieval encoder; it is not using
a separate five-class classifier at runtime.

## Outputs

The diagnostic produces:

- Top-1 category confusion matrix
- Top-1 cross-category mismatch rate
- most frequent cross-category pairs
- category hit rate over the annotated Top-1/5/10 ranks
- per-query Top-10 category distributions

The annotation set contains 100 validation queries (20 per category), so these
figures are a development diagnostic and not a full-population benchmark.

## Run

```bash
python scripts/run_s4_9_category_confusion_diagnostic.py
```

Optional paths:

```bash
python scripts/run_s4_9_category_confusion_diagnostic.py \
  --annotations path/to/s4.9_human_relevance_annotations.csv \
  --output path/to/report.json
```

The result is written to
`experiments/final_evaluation/s4.9/human_relevance/s4.9_category_confusion_report.json`.

No Sprint 5 training decision is made automatically by this script.
