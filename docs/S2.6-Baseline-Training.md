# S2.6 — Baseline Training

## Purpose

S2.6 performs the first real training run on Dataset 1 using the existing Custom CNN v1 + EmbeddingHead architecture and the reusable S2.5 training infrastructure.

The baseline objective is **category cross-entropy**. This is intentionally a reference objective, not the production retrieval loss. Product-pair sampling, distance functions, Contrastive Loss, and Siamese training remain S3 responsibilities.

## Architecture

```text
RGB image
  ↓
ImagePreprocessor
  ↓
CustomCNNEncoder
  ↓
EmbeddingHead
  ↓
L2-normalized embedding
  ↓
BaselineClassifier (temporary S2.6 head)
  ↓
5-category logits
  ↓
CrossEntropyLoss
```

The temporary classifier is not part of the production retrieval model. The embedding path remains the existing S2.3 contract.

## Data policy

Only `train` and `valid` are loaded. The `test` split is never used for training, model selection, or tuning.

Dataset 1 validation contains one image per product group, so same-product Recall@K cannot be computed honestly from validation alone. S2.6 therefore records category accuracy and embedding L2-norm health. Retrieval metrics are introduced with the gallery/query design in S2.7/S3.

## Recorded outputs

- train loss per epoch
- validation loss per epoch
- learning rate per epoch
- epoch duration
- total training duration
- completed epoch / early stopping state
- validation category accuracy
- embedding norm mean/std
- hardware and CUDA metadata
- checkpoint paths
- complete training history

## CLI

```powershell
python -m scripts.train_baseline --manifest <manifest.csv> --dataset-root <dataset-root>
```

Useful overrides:

```powershell
--epochs 10
--batch-size 16
--embedding-dim 128
--learning-rate 0.001
--weight-decay 0.0001
--seed 42
--device auto
--num-workers 0
--no-augmentation
```

## Definition of Done

- Real Dataset 1 train/validation data is used.
- Existing preprocessing and augmentation contracts are reused.
- Existing Custom CNN v1 and EmbeddingHead are reused without modification.
- S2.5 Trainer is reused without duplicating training infrastructure.
- Category loss, validation loss, time, accuracy, checkpoints and reproducibility metadata are recorded.
- Test split remains untouched.
- Unit and integration tests pass.
- A real baseline run produces a JSON benchmark report.
