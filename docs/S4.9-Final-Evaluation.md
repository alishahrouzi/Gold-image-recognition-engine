# S4.9 — Final Unseen-Image Evaluation

## Purpose

S4.9 freezes the S3.13 candidate checkpoints and evaluates them on Dataset 1
validation/test images that were not used for training or model selection.
No retraining, hyperparameter tuning, or threshold tuning is performed on the
final test split.

## Dataset protocol

- Gallery: Dataset 1 `train` only.
- Development generalization: Dataset 1 `valid` against the train gallery.
- Final generalization: Dataset 1 `test` against the train gallery.
- Query images are never inserted into the gallery.
- Product identity is never inferred from the filename.
- Dataset 1 `valid` and `test` product groups are singleton groups, so exact
  product retrieval is not a valid automatic ground-truth metric for these
  splits. The automatic final-test ground truth is the manifest category.

## Automatic metrics

For each query, the engine retrieves Top-10 unique products using the frozen
checkpoint and existing S3.8/S3.9 search/ranking path. We report:

- category Top-1 hit
- category Top-5 hit
- category Top-10 hit
- category MRR
- mean first correct-category rank
- the same metrics per category

The report also stores the complete Top-10 product candidates for each query.
This preserves the evidence required for a later human visual-relevance pass.

## Robustness protocol

A deterministic subset of queries is evaluated in five conditions:

1. original image
2. +12 degree rotation, bilinear, `expand=False`
3. +20% brightness
4. centered 90% crop
5. 50% resize followed by the normal preprocessing resize

For every condition we report category Top-1/5/10 and category MRR.

## Model selection

All frozen candidates are evaluated with the same gallery, query split,
preprocessing, K, and metric definitions. The selection priority is:

1. test category Top-1
2. test category Top-5
3. test category MRR

This is a model-selection rule for this MVP benchmark, not a claim that the
selected model has production-level visual-search accuracy.

## Human visual-relevance benchmark

Category correctness is not equivalent to visual similarity. S4.9 therefore
exports ranked candidates so a later annotation set can label Top-10 results
for a small held-out query sample. Exact visual-search claims should use that
human-labeled relevance benchmark rather than category accuracy alone.

## Command

Provide each frozen S3.13 best checkpoint using `MODEL=PATH` syntax. Example:

```bash
python scripts/run_s4_9_final_evaluation.py \
  --checkpoint s3.4_hybrid=PATH_TO_CHECKPOINT \
  --checkpoint s3.5_random=PATH_TO_CHECKPOINT \
  --checkpoint s3.5_same_category=PATH_TO_CHECKPOINT \
  --checkpoint s3.5_cross_category=PATH_TO_CHECKPOINT \
  --split test
```

For development validation, use `--split valid`. To skip robustness during a
quick smoke run, use `--skip-robustness`.

## Integrity rules

- Do not retrain any model after seeing test metrics.
- Do not modify the test set based on results.
- Do not select a model using test results and then report those same results
  as an unbiased estimate of a post-selection model.
- Keep the S3.13 model-selection result as the pre-test selection record.
- If Model V2 is required, restart model selection with a new development
  protocol and keep the untouched test result as a historical benchmark.
