# S4.7 — MVP UI

S4.7 adds a dependency-free HTML/CSS/JavaScript interface on top of the existing S4.4 `/search` API.

## Flow

`Upload Image → Search → Results`

The UI shows:

- query image preview
- category from the public API response
- product ID
- Similarity Score
- representative matched product image when the gallery image is available
- API error code and message for the S4.6 error envelope
- network/unexpected client-side failures

## Architecture

The browser does not run inference or access gallery files directly. It sends the selected image as multipart form data to `/search`, consumes the stable S4.5 response schema, and requests matched images through `/result-image/{product_id}`. The server resolves images only from trusted runtime gallery metadata.

The UI is intentionally limited to vanilla HTML, simple CSS, and browser JavaScript. No frontend framework or build pipeline is introduced.

## Runtime model

S4.9 selected `s3.5_cross_category` using validation-only model selection. The MVP runtime defaults are aligned with this selected model and its corresponding S3.7 train gallery. The untouched S4.9 test split is confirmation only and does not change the runtime selection.

## Run

```bash
python scripts/run_api.py --checkpoint <path-to-s3.5_cross_category-siamese-checkpoint>
```

Then open `http://127.0.0.1:8000/`.
