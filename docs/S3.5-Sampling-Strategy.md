# S3.5 — Sampling Strategy

## Objective

Evaluate explicit negative-pair sampling strategies without changing the Siamese architecture, distance function, contrastive loss, or retrieval pipeline.

## Strategies

1. **Random Negative** — choose two images from different product groups without conditioning on category.
2. **Same Category Negative** — choose images from different product groups within the same category.
3. **Different Category Negative** — choose images from different categories (and therefore different product groups).
4. **Hybrid 50/50** — the existing S1.10 configuration used by S3.4: 50% same-category and 50% different-category negatives.

## Existing infrastructure

S1.10 already implements group-aware positive generation and same-category/cross-category negative sampling. S3.5 adds an explicit random-negative strategy and a common dispatcher rather than creating a second pair-generation system.

The S1.10 Dataset 1 pair report contains 8,376 pairs: 4,188 positives, 2,094 same-category negatives, and 2,094 cross-category negatives. Its validation checks passed, including no self-pairs, no duplicate unordered pairs, split isolation, and no cross-split group leakage.

## Experiment protocol

Each strategy must use deterministic seeds and equivalent positive/negative counts. Strategy-specific pair reports should record counts by negative type and split. Models trained from different strategies must be evaluated with the same query set, gallery, preprocessing, similarity metric, product aggregation, and Top-K/MRR metrics.

The existing S3.4 Hybrid 50/50 model is the first reference model. Random, Same Category, and Different Category variants are separate experiments; their checkpoints and reports must not overwrite one another.

## Scope boundaries

S3.5 does not modify:

- `SiameseNetwork`
- `DistanceFunction`
- `ContrastiveLoss`
- CNN architecture or embedding dimension
- retrieval ranking logic
- baseline evaluation results

The purpose is to isolate the effect of negative sampling.
