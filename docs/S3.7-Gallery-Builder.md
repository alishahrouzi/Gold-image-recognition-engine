# S3.7 — Gallery Builder

## Decision

S3.6 established that all four trained Siamese variants produce useful image-level embedding geometry, while it did not provide final retrieval ranking evidence. Therefore S3.7 builds the common retrieval gallery before model selection. No architecture change is made here.

## Gallery contract

Each gallery row represents one catalog image:

- `product_id`: product identity (`group_id` from the dataset manifest)
- `category`: canonical category name
- `image`: resolved image path
- `embedding`: stored in the aligned `gallery_embeddings.pt` tensor

The metadata JSON keeps the legacy S2.7 fields (`product_group`, `image_id`, `image_path`, etc.) for compatibility. `embeddings[i]` always corresponds to `metadata[i]`.

Product-level aggregation is intentionally not performed during gallery construction. It remains a retrieval/ranking concern so that different aggregation policies can be evaluated without rebuilding embeddings.

## Models

The builder creates aligned galleries for:

1. S3.4 Hybrid50/50
2. S3.5 Random Negative
3. S3.5 Same Category Negative
4. S3.5 Different Category Negative

All use the same Dataset 1 train split, preprocessing, ordering, batch size, and seed. The script verifies that metadata ordering is identical across all four galleries.

## Output

`experiments/retrieval/siamese/<model>/`

- `gallery_embeddings.pt`
- `gallery_metadata.json`
- `gallery_report.json`

And one cross-model summary:

- `experiments/retrieval/siamese/s3.7_gallery_summary.json`

## Scope and leakage

The gallery is intentionally built from the train split because the current valid/test splits contain one image per product. This makes S3.7 an infrastructure step, not a clean generalization evaluation. Final model comparison must be performed by the subsequent retrieval evaluation using a fixed query/gallery protocol.

## Reproducibility

Policy: `s3.7-image-level-gallery-v1`.

The gallery builder uses the existing deterministic manifest, preprocessing pipeline, non-shuffled DataLoader, seed, and strict Siamese checkpoint loading.
