# S3.12 - Compare Baseline vs Metric Learning

This task compares the S2.8 baseline with the selected S3.11 metric-learning retrieval model.

Official metrics: Top-1, Top-5, and MRR.

Inputs:
- reports/evaluation/s2.8_baseline_evaluation.json
- reports/evaluation/s3.11_retrieval_evaluation.json

Outputs:
- reports/evaluation/s3.12_baseline_vs_metric_learning.json
- reports/evaluation/s3.12_baseline_vs_metric_learning.md

The default Siamese model is s3.5_random because it has the best S3.11 Top-1, Top-5, and MRR. An explicit --siamese-model override is supported.

Absolute change = metric_learning - baseline.
Relative change = absolute_change / baseline. If baseline is zero, relative change is null.

S3.12 does not change the model, retrieval engine, ranking, scoring, or S3.11 evaluation protocol. It is a controlled comparison under the existing train leave-one-image-out protocol and is not a final test-set generalization score.

Policy: s3.12-baseline-vs-metric-learning-v1
