# S3.4 — Siamese Training

## Purpose

S3.4 connects the metric-learning components already implemented in Sprint 3
and trains the shared Siamese encoder with the existing S2.5 training
infrastructure.

```text
Existing Pair CSV
      ↓
PairDataset
      ↓
SiameseNetwork
      ↓
Embedding A / Embedding B
      ↓
EuclideanDistance
      ↓
ContrastiveLoss
      ↓
Trainer
      ↓
Backpropagation + AdamW
```

## Existing components reused

- S1.10 pair generation and `Pair` contract — no new pair-generation policy.
- S1.8/S1.9 preprocessing — image loading and deterministic preprocessing.
- S3.1 `SiameseNetwork` — one shared `EncoderWithEmbeddingHead`.
- S3.2 `EuclideanDistance` — lower-is-better aligned pairwise distance.
- S3.3 `ContrastiveLoss` — classic margin-based contrastive objective.
- S2.5 `Trainer` — optimization, validation, scheduler, checkpoints,
  reproducibility, and early stopping.

## Label conventions

The historical S1.10 Pair contract stores `label=1` for positive pairs and
`label=0` for negative pairs. S3.3 ContrastiveLoss uses the opposite convention:
`0` positive and `1` negative. `PairDataset` performs this conversion only in
the training batch and leaves the persisted Pair contract unchanged.

## Split policy

S3.4 uses `train` pairs for optimization and `valid` pairs for validation.
`test` pairs are loaded only for reporting the available count and are not used
for optimization or validation.

## Reproducibility

The CLI defaults are aligned with the established baseline experiment:
seed=42, embedding_dim=128, batch_size=16, epochs=10, learning_rate=1e-3,
weight_decay=1e-4, margin=1.0, AdamW, cosine scheduler, deterministic mode,
and automatic device selection.

## Scope boundaries

S3.4 does not change the CNN architecture, retrieval pipeline, gallery,
retrieval evaluation, hard-negative mining, FAISS integration, or test-set
retrieval metrics. It also does not regenerate pairs during training.

## Entry point

```bash
python scripts/train_siamese.py
```

The script reads `reports/dataset/dataset1_manifest.csv` and
`reports/dataset/dataset1_pairs.csv`, then writes checkpoints under
`experiments/siamese/checkpoints` and a JSON training summary under
`experiments/siamese/training_summary.json`.
