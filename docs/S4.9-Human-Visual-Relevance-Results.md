# S4.9 — Human Visual-Relevance Evaluation Results

Run this evaluator only after completing the annotation CSV produced by the S4.9 annotation runner.

    python scripts/evaluate_s4_9_human_relevance.py

The evaluator reports:

- Precision@1/5/10 using relevance >= 2 as binary relevant
- Hit@1/5/10
- mean graded relevance at 1/5/10
- graded nDCG@5/10
- overall and per-category results
- query-level results for later error analysis

Because the current protocol uses one annotator, inter-annotator agreement is recorded as unavailable rather than fabricated.

These human labels are development evidence for visual-search quality and error analysis. They must not retroactively change the S4.9 validation-only model-selection decision.
