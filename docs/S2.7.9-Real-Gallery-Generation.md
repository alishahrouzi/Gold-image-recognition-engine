# S2.7.9 — Real Gallery Generation

## Purpose

Build the first real baseline retrieval gallery from Dataset 1 using the best S2.6 checkpoint and the existing preprocessing/model contracts.

## Protocol

```text
S2.6 best.pt
    ↓
CustomCNNEncoder
    ↓
EmbeddingHead
    ↓
L2-normalized 128-D embedding
    ↓
Dataset 1 train split
    ↓
4328 gallery embeddings
```

The gallery uses the `train` split only. The validation and test splits are not used during gallery construction.

## Expected verification

- embeddings: 4328
- product groups: 1494
- embedding dimension: 128
- embeddings finite: yes
- embedding norms approximately 1.0
- test split used: false
- metadata rows equal embedding rows

## CLI

From the project root:

```powershell
python scripts/build_baseline_gallery.py --manifest <manifest.csv> --dataset-root <dataset-root>
```

The default checkpoint is:

```text
experiments/baseline/checkpoints/best.pt
```

The default output directory is:

```text
experiments/retrieval/baseline/
```

Optional overrides:

```powershell
--checkpoint <best.pt>
--output-dir <output-dir>
--batch-size 16
--embedding-dim 128
--seed 42
--device auto
--num-workers 0
```

## Outputs

```text
experiments/retrieval/baseline/
├── gallery_embeddings.pt
├── gallery_metadata.json
└── gallery_report.json
```

`gallery_report.json` records the gallery size, group count, category distribution, embedding norm statistics, input paths, device, seed, duration, and verification results.

## Important evaluation rule

This stage does not report Recall@K. Dataset 1 has zero product-group overlap between train and validation, so a validation query has no same-product target inside the train gallery. Retrieval metrics must be introduced only with a valid query/gallery evaluation protocol.

## Definition of Done

- Real best checkpoint loads successfully.
- Existing preprocessing/DataLoader stack is reused.
- Exactly 4328 train embeddings are generated.
- Exactly 1494 train product groups are represented.
- Embedding dimension is 128.
- All embeddings are finite and L2-normalized.
- Gallery and metadata are persisted.
- JSON verification report is generated.
- Test split is not accessed.
