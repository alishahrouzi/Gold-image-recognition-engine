# S3.10 — Similarity Score

## Objective

Convert the raw similarity evidence produced by S3.8/S3.9 into a stable, human-readable **Similarity Score** for the MVP retrieval output.

The score is a display metric. It is **not Probability**, confidence, or a calibrated likelihood that the product is correct.

## Pipeline position

```text
Query Embedding
      ↓
S3.8 Similarity Search
      ↓
ProductSearchResult
      ↓
S3.9 Product Ranking
      ↓
RankedProductSearchResult
      ↓
S3.10 Similarity Score
      ↓
ScoredProductSearchResult
```

## Current MVP metric

The active retrieval pipeline uses cosine similarity.

Cosine similarity is in `[-1, 1]`. S3.10 maps it linearly to a display score in `[0, 100]`:

```text
Similarity Score = (cosine_similarity + 1) × 50
```

Examples:

| Raw cosine similarity | Similarity Score |
|---:|---:|
| -1.0 | 0.0 |
| 0.0 | 50.0 |
| 0.5 | 75.0 |
| 0.9 | 95.0 |
| 1.0 | 100.0 |

The conversion is monotonic, so it does not change the ordering established by S3.9.

## Distance support

The converter also exposes deterministic mappings for metrics already present in the metric-learning layer:

- cosine distance `[0, 2]` → score `[100, 0]`
- Euclidean distance `[0, 2]` for normalized embeddings → score `[100, 0]`

The Euclidean mapping relies on the normalized-embedding range used by the current model. These conversions are utility functions; the active S3.10 product pipeline remains cosine-similarity based.

## Output contract

`ScoredProductCandidate` preserves:

- `rank` from S3.9
- `product_id`
- `category`
- raw `similarity`
- matched image IDs and paths

and adds:

- `similarity_score` — a display value in `[0, 100]`

`ScoredProductSearchResult` preserves `query_id` and the ranked candidate order.

## Responsibilities

### S3.10 owns

- deterministic raw-metric → Similarity Score conversion
- validation of metric ranges and finite values
- preserving S3.9 ranking and metadata
- keeping the score explicitly separate from probability

### S3.10 does not own

- embedding generation
- similarity search
- product aggregation
- ranking
- retrieval evaluation
- model comparison
- probability calibration

Those responsibilities remain in S3.8, S3.9, S3.11 and S3.12 as defined by the Sprint 3 plan.

## Validation

Tests cover:

- cosine similarity endpoint/midpoint conversion
- cosine distance conversion
- Euclidean distance conversion for normalized embeddings
- score order preservation
- raw similarity preservation
- metadata preservation
- empty results
- invalid metric names
- non-finite and out-of-range metric values
- invalid result types
- non-finite candidate similarity

Policy identifier: `s3.10-display-similarity-score-v1`.
